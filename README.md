# Boreal Stand Intelligence

Project 1 of a two-project geospatial portfolio piece on Finnish forestry,
targeting Metsa Group. This repository rebuilds three of Metsa's published
geospatial data products from open data: growing stock estimation (Module A),
harvest change detection (Module B), and bark beetle / insect damage mapping
(Module C). It is a batch analytical pipeline validated against official
products and ground truth, producing static figures and JSON reports. Companion
repository: `regenerative-harvest-planning`. This README is a stub and will be
written in full once the modules are complete.

Contains data from the Finnish Forest Centre, licensed CC BY 4.0. Contains
Natural Resources Institute Finland MS-NFI data, CC BY 4.0. Contains data from
the National Land Survey of Finland, CC BY 4.0. Contains modified Copernicus
Sentinel data. Contains Finnish Meteorological Institute open data, CC BY 4.0.
